어디서나 최신 프로그램 실행

이 주소를 관리자끼리 공유하면 별도 파일 복사 없이 항상 GitHub Pages의 최신 HAO 프로그램을 실행할 수 있습니다. Chrome 또는 Edge에서는 독립 앱으로 설치할 수 있습니다.

01 관리자툴 실행 프로젝트 검수, 기획 준비, 시안·피드백·납품 관리 02 고객 작성폼 고객이 제품 정보와 자료를 제출하는 접수 화면 03 시스템 상태 전체 공정의 연결·부분 연결·미연결 상태 확인 04 고객 진행조회 접수번호와 연락처 뒤 4자리로 제작 단계만 확인

현재 다른 컴퓨터에서도 공통 사용

프로그램 화면, 최신 기능, 공개 기준 데이터, 고객 작성폼과 시스템 상태 페이지는 같은 주소에서 최신본으로 실행됩니다.

업무 서버 연결 후 완전 동기화

각 브라우저의 로컬 수정값, IndexedDB 파일, 관리자별 작업 기록은 아직 자동 공유되지 않습니다. 동일 DB와 고객 원본의 실시간 공유에는 인증·저장 서버가 필요합니다.

현재 관리자 인증 서버 도입 전이므로 관리자툴 주소는 내부 관리자에게만 공유하세요. 고객에게는 고객 작성폼과 고객 진행조회 주소만 전달하는 것이 안전합니다.
